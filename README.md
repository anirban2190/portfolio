# Anirban Bhattacharyya — robotics portfolio

A single-page portfolio presenting my work in mobile robotics software. It covers ROS 2 navigation and localization, LiDAR and IMU integration, sensor fusion, motor interfaces, and field debugging. It also includes selected robot photos and videos.

## View the site

Open [index.html](index.html) in a browser. The page is static HTML and CSS, with local media under [images/](images/); there is no build step.

## What you will find

- **Experience and project areas:** mobile robot integration, localization, navigation, perception, and control.
- **Field investigations:** examples of debugging geometry, startup localization, and deployed robot behavior.
- **Demos:** videos and images from robotics work.
- **Contact:** links on the page for email, LinkedIn, and GitHub.

The site is a personal overview. The individual public repositories linked from my [GitHub profile](https://github.com/anirban2190) contain separate code and materials.

## Editing

Update [index.html](index.html) for text, layout, and links. Keep referenced media in [images/](images/) and check the page in desktop and mobile browser widths after editing.
